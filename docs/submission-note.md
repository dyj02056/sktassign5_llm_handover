## 0. 과제 이해

과제 5는 "대화가 끊겨도 이어지는 프로젝트"로, 두 AI 세션을 이어서 작업을 완성하는 과제다.

- **AI A**가 작업을 시작하고, 일부만 구현한 뒤 멈춘다.
- **AI A**가 저장소와 인수인계 문서를 남긴다.
- **AI B**는 AI A와의 대화 전문 없이, 저장소와 인수인계 문서만으로 이어받아 완성한다.

핵심은 "AI의 기억"이 아니라 "저장소와 인수인계 품질"이다.

## 2. 스킬 적용

업로드한 3개 스킬을 다음과 같이 적용했다.

| 스킬 | 적용 지점 | 실제 적용 |
|---|---|---|
| `caveman-compress` | 인수인계 문서 압축 | 적용하지 않음 — 인수인계 문서가 이미 간결했고, 압축 시 검사 ID·commit hash 변형 위험 |
| `token-optimizer` | 컨텍스트 관리, 측정 | 방법론만 참고 — 턴 수·시간 수치화 원칙 적용 |
| `grill-me` | 계획 검증 | grilling 방식으로 진행 — 각 단계에서 "왜?"를 파고들어 결정 |

**참고**: `grill-me`는 `disable-model-invocation: true`라 자동 호출이 불가하여, grilling 방식(집요한 인터뷰)을 대신 수행했다.
