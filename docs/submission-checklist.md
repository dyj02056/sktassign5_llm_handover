## 재현·통과 확인 4가지

### 1. 어디로 가나요
https://sktassign5-llm-handover.vercel.app/ 를 **시크릿 창**에서 연다 (로그인 필요 없음).

### 2. 무엇을 하나요 (3단계 이내)
1. 좌측 상단 **"PNG · JPEG 불러오기"** 로 이미지를 고른다.
2. 좌측 **필터 영역**에서 밝기·대비·채도 슬라이더를 움직이거나, 흑백·세피아 체크박스를 켠다.
3. 우측 상단 **"이미지 다운로드"** 를 클릭한다.

### 3. 무엇이 보이면 통과
- 슬라이더/체크박스를 조작하면 **캔버스 이미지가 실시간으로 변한다**.
  - 밝기 150% → 원본보다 밝아짐
  - 밝기 0% → 검은색에 가까워짐
  - 대비 150% → 선명해짐
  - 대비 0% → 균일 회색
  - 채도 200% → 색이 진해짐
  - 흑백 체크 → 흑백으로 변함
  - 세피아 체크 → 갈색 톤으로 변함
- 다운로드한 PNG/JPEG가 **미리보기와 동일**하다 (필터 포함).

### 4. 안 될 때 (3단계 각각의 실패 시나리오 → 채점자 대응)

#### 1단계 — 이미지 불러오기가 안 될 때

| 증상 | 대응 |
|---|---|
| 파일 선택 창이 열리지 않음 | 페이지를 새로고침 후 다시 시도. 그래도 안 되면 브라우저를 최신 Chrome/Edge/Safari로 바꿔서 시도 |
| 빨간 토스트 **"지원하지 않는 형식: ..."** 가 뜸 | PNG·JPEG·WebP 파일인지 확인. `.gif`, `.bmp`, `.txt`는 지원하지 않음 |
| 파일을 골랐는데 캔버스가 안 보임 | 페이지를 새로고침 후 다시 시도. 다른 이미지 파일로 시도 (해당 파일이 손상됐을 수 있음) |
| 드래그&드롭이 안 됨 | 파일 선택 버튼("PNG · JPEG 불러오기")을 대신 사용 |

#### 2단계 — 필터 조작이 안 될 때

| 증상 | 대응 |
|---|---|
| 슬라이더를 움직여도 캔버스가 안 변함 | 이미지가 먼저 로드됐는지 확인 (이미지 없으면 배경색만 보임). 슬라이더를 0%와 200%로 극단적으로 움직여 변화 확인 |
| 흑백/세피아 체크박스가 안 보임 | 좌측 "1. 이미지" 섹션을 아래로 스크롤. 밝기·대비·채도 슬라이더 아래에 있음 |
| 흑백/세피아를 켜도 변화가 없음 | 밝기·대비·채도를 100%로 두고 다시 시도. 이미지가 흑백에 가까운 경우 변화가 안 보일 수 있음 |
| 필터를 여러 개 켰더니 이미지가 이상해짐 | 정상 동작. 필터는 조합 가능 (예: 밝기 150% + 흑백 + 세피아) |

#### 3단계 — 다운로드가 안 될 때

| 증상 | 대응 |
|---|---|
| 다운로드 버튼을 눌러도 파일이 안 받아짐 | 브라우저 다운로드 차단 설정 확인. 시크릿 창에서 다시 시도 |
| 다운로드한 파일에 필터가 안 보임 | 다운로드 전에 캔버스에 필터가 적용됐는지 확인. 캔버스에 보이는 그대로 저장됨 |
| 다운로드 파일이 미리보기와 다름 | 브라우저를 새로고침 후 다시 시도. 캔버스 크기(1:1, 4:5, 9:16)가 동일한지 확인 |
| 파일이 저장됐는데 열리지 않음 | PNG 또는 JPEG 형식으로 저장됐는지 확인. 우측 "내보내기" 섹션에서 형식 선택 가능 |

## AI와 내 판단 3줄

1. **AI에게 맡긴 일**: 이미지 필터 기능 구현 (AI A: 밝기·대비·채도, AI B: 흑백·세피아·다운로드 반영·경계값)
2. **내가 판단한 일**: 검사 10개 고정, AI A/B 역할 분할, 공통 턴 상한(8턴) 결정, 인수인계 문서 형식 확정, AI B 모델 선택(Manus)
3. **AI 말을 안 들은 일**: AI A가 자발적으로 작성한 `HANDOVER.md`를 그대로 쓰지 않고, 우리가 정한 7항목 형식(`handoff_between.md`)으로 재구성했다.
